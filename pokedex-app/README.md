# pokedex-app

Aplikasi React Native untuk Pokédex take-home test.

Dokumentasi lengkap — fitur, screenshot, cara menjalankan, arsitektur, dan keputusan teknis —
ada di [README utama](../README.md).

Ringkas:

```bash
npm install
cp .env.example .env
npm start
npm run android   # atau: npm run ios (setelah `cd ios && bundle exec pod install`)
```
